# 功能概览

本文档只描述当前 `superflare` 代码已经具备的能力。

## 首页

- 顶部搜索
- 实时日期与时间显示
- 自定义问候语
- 应用区与书签区分开展示
- 应用标题、书签标题可自定义
- 网站标题与网站图标可自定义
- 宽布局下使用对齐网格，窄布局下书签分类切换为瀑布流
- 支持自定义最大列数和展示区域最大宽度

## 书签能力

- 应用与普通书签分离
- 支持子目录折叠
- 书签分类文字颜色可自定义
- 书签文字颜色可自定义
- 支持站点图标、内置 MDI 图标与自动 favicon 回退
- 支持公网地址与内网地址双链路
- 内网访问时优先尝试 `local_link`

## 主题与背景

- 主题色可切换
- 支持自定义背景图 URL 或上传背景图
- 背景图支持模糊与透明度控制
- 玻璃效果作用于背景层，不作用于前景书签区
- 支持 frosted / liquid 两种背景玻璃模式

## 设置页

- 主题设置
- 搜索设置
- 页面展示设置
- 端口设置
- 登录设置

## 端口设置

- 独立 `/settings/ports` 页面
- 运行中端口可刷新读取
- 端口备注持久化到 `ports.yaml`
- 编辑页可直接选择带备注的 TCP 端口生成内网地址

## 编辑页

- 在线编辑分类与书签
- 支持 `local_link`
- 支持 `subdir`
- 支持备份下载与恢复导入
- 支持主动检查公网无效链接

## 帮助与跳转

- `/help` 无需登录即可访问
- 帮助页仅保留当前仍有效的入口
- `/redir/local` 针对局域网优先访问做了中英文落地页和失败倒计时回退

## 登录与安全

- 账号密码可来自环境变量、启动参数或配置文件
- 登录令牌有效期为 90 天
- 首页内联脚本带 nonce，兼容 CSP
