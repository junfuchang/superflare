# .tools 目录说明

这个目录用于存放项目构建、打包、运维脚本依赖的本地工具。

当前约定如下：

- `./.tools/fnpack/`
  - 用于存放 `fnpack.exe`
  - 该工具会提交到仓库，因为 `fnapp/build-superflare-fpk.ps1` 会直接使用它打包 fnOS 应用

- `./.tools/go/`
  - 用于存放本地 Go 工具链，例如 `go.exe`、`gofmt.exe`
  - 该目录不提交到仓库
  - 如本地未放在这里，也可以通过环境变量 `SUPERFLARE_GO_BIN` 指定 Go 可执行文件路径

建议继续遵守以下规则：

1. 这里只放项目脚本明确依赖的工具
2. 优先提交体积较小、分发麻烦但版本需要统一的工具
3. 不提交完整语言运行时、缓存、临时文件和大体积工具链
4. 新增工具时，优先在对应脚本中写清查找顺序和用途
