# Security Policy

## Supported Versions

SuperFlare currently follows the `main` branch as the maintained code line in
this repository.

| Version branch | Supported |
| -------------- | --------- |
| `main`         | yes       |

Historical upstream releases are not maintained in this fork.

## Reporting a Vulnerability

If you identify a security issue in the current SuperFlare code:

1. Open a private security report if the hosting platform provides one.
2. If private reporting is unavailable, contact the maintainer before opening a public issue.
3. Include the affected commit, reproduction steps, impact, and any proposed mitigation.

Please avoid publishing exploit details before the issue has been reviewed.
